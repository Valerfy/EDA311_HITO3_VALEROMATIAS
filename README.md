# EDA311_# EDA311_HITO3_VALEROMATIAS

Este proyecto consiste en una aplicación web desarrollada con PHP y MySQL para administrar las tablas de clientes, pedidos y productos. Permite registrar, consultar, modificar y eliminar datos. También utiliza el patrón MVC, una lista doblemente enlazada y el método Bubble Sort para ordenar los registros.

## Pasos para ejecutar el proyecto

1. Tener instalado XAMPP y Git en el equipo.

2. Abrir una terminal y clonar el repositorio de GitHub:

   git clone https://github.com/Valerfy/EDA311_HITO3_VALEROMATIAS.git

3. Copiar la carpeta descargada dentro de `C:\xampp\htdocs`.

4. Abrir XAMPP e iniciar Apache.

5. Abrir el navegador e ingresar a la siguiente dirección:

   http://localhost/EDA311_HITO3_VALEROMATIAS-main

6. Probar las operaciones de registro, consulta, modificación y eliminación, además del ordenamiento mediante Bubble Sort.
